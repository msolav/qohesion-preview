Nom et logo

Ébauche, pas encore examinée par un conseiller juridique. Elle précise l’avis sur la marque et ne constitue pas un avis juridique. Le nom ne fait l’objet d’aucun enregistrement de marque de commerce pour l’instant. Propriétaire des marques: [propriétaire, à nommer].

Ce que couvre cette politique

Le nom « Qohesion », le logo (le cercle dont la queue est une coche), le mot-symbole et les icônes. Elle ne couvre pas l’expression « Décidons ensemble », qui est courante, ni le code et les documents, dont les licences figurent dans LICENSING.md.

Pourquoi une politique

La licence du code permet à quiconque d’exploiter et de modifier le logiciel. Elle n’indique pas à une personne qui vote qui exploite l’installation qu’elle a devant elle. Un service qui imite Qohesion et utilise son nom sur une page de vote pourrait tromper les gens sur qui détient leurs données et qui compte les votes. Cette politique garde le nom lié à ce qu’il désigne vraiment.

Permis sans demande préalable

  1. Dire que Qohesion est utilisé, en texte simple : « vote avec Qohesion », « conçu avec Qohesion », « cette organisation héberge une installation de Qohesion ».
  2. Montrer le logo non modifié, à une taille lisible et avec un lien vers le projet, pour indiquer que Qohesion est utilisé.
  3. Exploiter une installation sous le nom de l’organisation, avec la mention « propulsé par Qohesion » et un lien vers le projet.
  4. Écrire sur Qohesion de façon exacte : articles, comptes rendus, tutoriels, conférences et comparaisons.
  5. Redistribuer une version officielle non modifiée sous son nom.
  6. Traduire les documents et l’interface. Le nom n’est pas traduit.

Permission écrite requise

  1. Une version modifiée sous ce nom. Une version modifiée prend son propre nom et son propre logo. La mention « basé sur Qohesion » est permise si le texte indique que la version est modifiée. Le code source d’une version modifiée est publié comme l’exige l’AGPL.
  2. Un service hébergé qui porte ce nom. Un service, un nom de domaine, une application ou un compte de réseau social dont le nom contient « Qohesion », ou un nom qui s’y confond, exige une permission. L’offre peut être décrite comme de l’« hébergement pour Qohesion ».
  3. Des articles promotionnels qui portent le nom ou le logo.
  4. Un logo modifié : recoloré, animé, rogné, ou utilisé comme logo d’autre chose.
  5. Toute affirmation d’appui, de partenariat, de certification ou de statut officiel.

Le service officiel

Seul le service exploité par le propriétaire du projet peut se dire le service officiel de Qohesion. Son adresse est publiée sur qohesion.app. Une installation à toute autre adresse n’est pas le service officiel, même si elle exécute du code non modifié.

Demander une permission ou signaler un abus

Les demandes sont adressées à [adresse de contact] et indiquent qui les présente, l’usage prévu et l’endroit où il paraîtra. Il y est répondu dans un délai de [15 jours ouvrables].

Changements à cette politique

Les changements sont inscrits au journal des modifications. Un usage conforme à la politique au moment où il a commencé dispose d’au moins [60 jours] pour s’adapter après un changement.
