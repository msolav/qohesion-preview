Glossary

Terms used in the interface, the emails and the documentation, with the French form the interface uses. Each term is defined where it first appears on a page (see content-style.md). French follows the Office québécois de la langue française where it has a recommendation. The list was confirmed on 2026-11-26 and is open to revision; a review by a French-language reader is still planned.

English French Meaning
organization organisation The group that holds votes: an association, cooperative, union, club, board or council.
member membre A person who belongs to the organization.
administrator administrateur, administratrice A person who prepares a vote and holds a share of the key that opens the count.
owner titulaire du compte A person who manages the account of the organization (billing, settings, deletion).
poll scrutin (or sondage for an informal poll) A decision or consultation put to the members, with one or more questions.
ballot bulletin de vote The answers of one member to a poll, once submitted.
roll liste des votants The list of addresses allowed to vote in a poll.
registration inscription The step in which a member confirms their own address and joins the roll.
frozen roll liste des votants figée The roll once registration has closed. Published as a count and a short code.
roll code code de la liste The short code that identifies the exact content of the frozen roll.
quorum quorum The minimum number of registered members who must vote for the result to be valid.
passing rule règle d’adoption The share of the votes cast that is required to adopt a proposal (simple majority, two-thirds).
secret ballot scrutin secret A ballot recorded without the voter's name.
receipt code code de reçu The short code displayed after a ballot is submitted. It allows checking later that the ballot is in the count. It does not reveal the choice.
ledger registre des bulletins The append-only list of recorded ballots, with a root hash that commits to all of them.
checkpoint point de contrôle The size and root hash of the ledger at one moment, published and timestamped.
assurance level niveau de garantie Informal, formal or reinforced: what the setup of administrators and keys allows to be checked.
threshold key clé à seuil A key split among administrators, of which a set number must act together to open the count (for example 2 of 3).
verification email courriel de vérification The message sent on request to confirm that an address belongs to the member who entered it.
template modèle The visual treatment of the ballot screen (Seed Packet, Ballot Paper).
